# icaOS2

icaOS2 is an operating system built from scratch. It is designed to be lightweight and efficient, providing a simple interface for users to interact with the system.

## Compilation Instructions

To compile icaOS2, you will need to have the following tools installed on your system:

### For Ubuntu:
You can install the necessary tools by running:
```bash
sudo apt-get install nasm gcc ld grub-mkrescue mtools xorriso
```

### For Arch Linux:
You can install the necessary tools by running:
```bash
sudo pacman -S nasm gcc ld grub-mkrescue mtools xorriso
```
